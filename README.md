# Industrial Trinidad & Tobago Website

Static website project for a lumber, sawmill, steel, hardware, haulage, tree cutting, tree removal and land clearing company.

## Files

- `index.html` - complete one-page website with SEO metadata and structured data.
- `styles.css` - responsive industrial design system, light/dark themes and reduced-motion support.
- `script.js` - navigation, theme persistence, gallery filtering/lightbox and quote form validation.
- `robots.txt` and `sitemap.xml` - launch-ready placeholders.

## Launch Notes

Replace placeholder company details before publishing:
